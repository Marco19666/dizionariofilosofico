# Dizionario universale della storia della filosofia

Enciclopedia digitale, comparata e interattiva della storia della filosofia, con una prospettiva globale e plurale.

## Obiettivi
- Rappresentare le tradizioni filosofiche nei rispettivi contesti storici e linguistici.
- Collegare autori, opere, concetti, scuole, periodi e luoghi.
- Offrire percorsi cronologici e comparativi senza imporre una periodizzazione unica.
- Distinguere le influenze storiche documentate dalle analogie interpretative.
- Pubblicare contenuti verificabili, corredati da fonti e bibliografia.

## Stack iniziale
- Next.js (App Router), React e TypeScript
- CSS
- Node.js 20.9 o successivo

## Avvio in locale
```bash
npm install
npm run dev
```
Apri http://localhost:3000.

## Stato
Fase iniziale: fondazione dell'applicazione e prototipo navigabile. Le schede dimostrative dovranno essere verificate e ampliate prima della pubblicazione scientifica.

## Struttura
- `app/`: pagine e stili
- `data/`: dati editoriali
- `docs/`: documentazione metodologica e tecnica

## Principio editoriale
La comparazione non implica equivalenza: ogni concetto deve essere presentato nel proprio contesto storico, linguistico e culturale.
